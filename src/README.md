# Source snapshot

The working application is currently maintained as a **Claude.ai Artifact**.

This repository documents the current architecture and behavior of a tool developed for an academic research workflow in Civil Engineering. The current Artifact source should be mirrored here only after exporting the reviewed version that includes the runtime-fallback, quotation-verification, chunk-failure, and MCP-safety corrections described in the documentation.

An earlier experimental source snapshot is intentionally not published because it predates those corrections.

When the current Artifact is exported, its main React source belongs at `src/App.jsx` (or an equivalent application structure if converted into a standalone React/Vite project).
